## Server-Side Tracking

For enhanced privacy and accuracy, use our server-side tracking endpoints. This method is immune to ad blockers and provides more reliable data collection.

<ExpandableGroup>
  <Expandable title="API Endpoints" default-open="true">
    Send conversion data directly to our servers using REST API calls.

    ```javascript
const conversion = {
  pixelId: 'your-pixel-id',
  event: 'purchase',
  value: 99.99,
  currency: 'USD',
  userId: 'user123',
  timestamp: new Date().toISOString()
};

fetch('https://api.anytrack.com/v1/track', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer your-api-key'
  },
  body: JSON.stringify(conversion)
});
    ```
  </Expandable>
  <Expandable title="Webhook Integration" default-open="false">
    Configure webhooks from your e-commerce platform or CRM to automatically send conversion data to AnyTrack.
  </Expandable>
</ExpandableGroup>

<Steps>
  <Step title="Generate API Key" icon="key">Create an API key in your AnyTrack dashboard for server-side authentication.</Step>
  <Step title="Configure Endpoints" icon="settings">Set up your server to call AnyTrack's tracking endpoints on conversion events.</Step>
  <Step title="Test Implementation" icon="check">Use our testing tools to verify data is being received correctly.</Step>

## Attribution Configuration

Configure how AnyTrack attributes conversions across your marketing touchpoints. Choose from multiple attribution models or create custom rules.

| Model | Description | Best For |
|-------|-------------|----------|
| First Touch | Credits initial interaction | Brand awareness campaigns |
| Last Touch | Credits final interaction | Direct response campaigns |
| Linear | Equal credit across touches | Multi-step customer journeys |
| Data-Driven | ML-based attribution | Advanced optimization |

<Expandable title="Custom Attribution Rules" default-open="false">
  Create custom attribution models using our rule builder. Set time decay, position-based weighting, and channel-specific rules.

  ```javascript
const customModel = {
  name: 'Custom Model',
  rules: [
    { channel: 'paid_search', weight: 0.4 },
    { channel: 'social', weight: 0.3 },
    { channel: 'email', weight: 0.3 }
  ],
  timeDecay: 'exponential',
  lookbackWindow: 30
};
await anytrack.createAttributionModel(customModel);
  ```
</Expandable>
